## Методика
14 направлений, каждое разбито на 10 равновесных контрольных единиц (всего 140). Баллы дают только за документируемые части: готовый код, автоматические тесты и подтверждённую компиляцию. Одна единица = 10% направления и 0.7143 п.п. общей готовности. Эти баллы — **индекс подтверждённого программного покрытия требований**, не прогноз завершения исследования, не гарантии качества музыки, не процент испытаний на телефоне. До успешной CI-сборки новое нативное покрытие считается предварительным. Текущая опорная успешная CI-сборка: https://github.com/BauRP/pixel-perfect-replica/actions/runs/42431583556 (18 тестов, TypeScript + Android APK).

Общий индекс **до пакета**: 19/140 = 13.57%.
Общий индекс **после успешных проверок пакета**: 30/140 = 21.43% (прирост **+7.86 п.п.**).

## Принципы
- Позднее решение отменяет старые записи о Stable Audio и вокале. Только **инструментальная** генерация; модель **Magenta RealTime 2 Small** + распознавание **YAMNet**.
- Никаких готовых песен вместо живого музыкального ИИ, ложных данных окружения, «работает на Android 17» без проверки.
- Микрофон только после явного действия (Play или диагностика); без микрофона должен быть настоящий музыкальный режим, когда будет реализован генератор.
- 11 параметров Studio, 150 жанров, любимые инструменты, обработка звуков, шаги->бит; не ломать готовую оболочку.
- Пользовательские действия на устройстве отмечать отдельно от программной готовности.
- При каждом запуске обновлять **эту же таблицу**, фиксировать действительную разницу, тесты, номер коммита и GitHub Actions.
