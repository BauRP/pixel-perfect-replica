# Аудиомодели SoundWorld AR: правила комплектации APK

Это **не подключённая Fermata**. Пока `offline-music/` отсутствует, сборка делает честную shell-only APK с YAMNet и без генерации. Ручная проверка телефона и эмулятора не является незавершённой программной задачей.

Для разрешённой автономной музыки нужен полный, проверенный пакет `offline-music/manifest.json`, который можно создать только после интеграции **оригинальной** `haster/Fermata-0.2B-v1`, её `tokenizer_v2`, MNN и синтезатора с банком инструментов. Каждый используемый код/вес/сэмпл должен допускать закрытое распространение по Apache-2.0. Нельзя считать лицензию подтверждённой одним полем JSON: оно фиксирует ручной аудит, а SHA256 подтверждает целостность.

Минимальная структура:
```json
{
  "schemaVersion": 1,
  "model": "haster/Fermata-0.2B-v1",
  "runtime": "Alibaba/MNN",
  "reviewedBy": "Имя ответственного за проверку лицензий",
  "reviewedAt": "2026-11-19",
  "files": [
    {
      "path": "model.mnn",
      "role": "model",
      "license": "Apache-2.0",
      "owner": "Владелец артефакта",
      "sourceUrl": "https://example.org/verified-revision",
      "sha256": "64 шестнадцатеричных символа SHA256",
      "sizeBytes": 123,
      "noticePath": "licenses/model.txt"
    }
  ]
}
```

Указанный пример **не готов для упаковки**. Требуются настоящие файлы с ролями `model`, `tokenizer`, `mnn-arm64`, `synth-arm64`, `soundbank`, `notice`. Файлы `.so` идут в `jniLibs/arm64-v8a`, остальные в `assets/offline-music`. Каждый файл заносится в manifest с SHA256, владельцем, URL источника и точным текстом лицензии в перечисленном `notice`. Сумма до 900 MB для модели и инструментов, без сетевых загрузок во время работы. Все неподписанные или посторонние файлы запрещены.

Команды: `node scripts/validate-offline-music-assets.mjs` проверяет пакет, `node scripts/validate-offline-music-assets.mjs --stage android/app/src/main` помещает подтверждённые файлы в генерируемый проект Android. При неправильной лицензии, размере, хеше или недостающем файле процесс **останавливает сборку**. Это не доказывает качество звучания, успешность конвертации Fermata или работу JNI и не заменяет юридический аудит. Никаких фальшивых PCM или демозвуков не добавляется.
