# SoundWorld AR — Phase 2 Android baseline (8 November 2026)

## What the source currently does
This branch adds an **offline, static Android web bundle path** without replacing the Lovable/TanStack website build. Local Manrope and Unbounded Cyrillic/Latin fonts replace remote Google Fonts (same font families), and the three-tab shell receives responsive width and navigation safe-area spacing. A Capacitor 8 configuration is prepared; its Android host is generated by the CLI, not claimed to exist in source control. Buttons requiring music AI still return honest UNAVAILABLE messages.

## Build commands
- Node 22+, Android Studio and Android SDK required.
- `npm install --no-package-lock` (packages are fetched from npm; no model downloads in app).
- `npm run test` and `npm run build` for existing web interface.
- `npm run build:android:web` builds `dist-android/index.html` with local web assets.
- `npx cap add android` once, then `npx cap sync android` after changes (or `npm run android:add` for initial setup).
- `cd android && ./gradlew assembleDebug` creates a **shell-only debug APK**. No Magenta/YAMNet inference is implemented yet.

## API / Android version policy
- Planned **minimum supported OS**: Android 12 (API 31); set `minSdkVersion=31` in the generated `android/variables.gradle` before release.
- Capacitor 8 supports build target API 36, and can run on Android 17 devices but this is NOT a verified compatibility claim.
- Target API 37 should be adopted with supported Capacitor 9 and a compatible SDK/Node toolchain; do not set an unsupported target manually or pretend this was compiled with API 37.
- No fixed portrait-only orientation: Android 17 large windows may freely resize. UI should adapt to font scaling, large/small screens and both gesture/three-button navigation; automated and device verification remain required.

## Next native integration (unimplemented)
1. Verify Android CPU/GPU/NPU feasibility and real-time speed of **Magenta RealTime 2 Small** before claiming that it runs on a phone. Google's official runtime is MLX/Apple Silicon; no verified Android real-time path in this project yet. Do not add a fake generator.
2. Implement local **YAMNet** inference and actual microphone/step sampling with user permission on Play; never capture by default, never upload conversations.
3. Implement Android foreground media service/MediaSession, audio focus/calls/headphone disconnect, session ownership and cancellation/timeouts.
4. Wire actual generated audio PCM, seamless playback, 120-s exports/last 3/favorites, and observed environment state to existing typed adapters.
5. Validate performance, heat, memory and battery, Android 12–17, window layouts and APK install. Device acceptance is separate from code completeness.
